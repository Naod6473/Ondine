# Sécurité · Security

**Français** · [English](#english)

Vous avez trouvé une faille dans Ondine ? Merci de ne pas ouvrir d'issue publique.
Signalez-la en privé depuis l'onglet **Security** du dépôt, bouton
[**Report a vulnerability**](https://github.com/Naod6473/Ondine/security/advisories/new).

Décrivez ce qui se passe, la version d'Ondine et de Windows, et comment le
reproduire. Je réponds dès que possible ; le correctif sort dans une nouvelle
version, proposée à tous par la mise à jour automatique.

Seule la dernière version publiée reçoit des correctifs.

<a id="english"></a>
## English

Found a security issue in Ondine? Please do not open a public issue. Report it
privately from the repository's **Security** tab,
[**Report a vulnerability**](https://github.com/Naod6473/Ondine/security/advisories/new).

Include what happens, the Ondine and Windows versions, and how to reproduce it.
Fixes ship in a new release, offered to everyone through the built-in updater.
Only the latest release receives security fixes.
