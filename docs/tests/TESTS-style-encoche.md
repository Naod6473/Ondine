# Tests Windows : le style d'île « Encoche »

Avant de commencer, quittez toutes les Ondine (Gestionnaire des tâches), puis lancez `npm.cmd run tauri dev`.

1. Réglages → L'île → Style de l'île : une 3e vignette « Encoche » apparaît (une encoche noire avec sa lueur). Cliquez dessus.
2. La mini-île devient noire pure, collée au bord du haut. De chaque côté, un petit coin creux la fond dans le bord de l'écran (pas de marche, pas de liseré).
3. Une lueur à la couleur du thème monte du bas de l'île. Changez le thème (Lagon, Prune…) : la lueur suit.
4. Avec un thème clair (Givre), l'île reste noire (le thème redevient Nuit, comme pour Bouche d'Ondine).
5. Ouvrez l'île : coins creux plus grands, arrondi plus marqué. Les onglets et les raccourcis sont les mêmes qu'avant.
6. Glissez un fichier sur l'île : la lueur devient plus forte et respire tant que vous tenez le fichier. Le menu de fichiers marche comme avant.
7. Une alerte (agent qui a fini, minuteur) : la lueur est un peu plus forte.
8. Déplacez l'île en bas, à gauche, à droite : les coins creux et la lueur suivent le bord.
9. Tirez Ondine hors de l'île (Ondine sur le bureau) : rien n'est coupé pendant qu'on la porte.
10. Mode 8 bits (si activé) : les lignes de balayage restent, sans lueur.
11. Repassez en Classique puis en Bouche d'Ondine : plus de coins creux ni de lueur, tout redevient comme avant.
12. Zoom Windows à 125 % et 150 % : les coins creux restent nets, sans trait clair entre eux et l'île.
