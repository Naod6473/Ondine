# Tests Windows : nouvelle fenêtre des Réglages (1.2.4)

À vérifier sur Windows 11 (avec Mica) et, si possible, sur Windows 10. Ouvrir
les Réglages depuis l'île.

## Le style

- [ ] Thème sombre de Windows : fond noir profond, barre latérale posée dessus sans trait ni verre, tout le contenu dans une grande carte arrondie, réglages dans des cartes un ton plus clair.
- [ ] Thème clair de Windows : même disposition, surfaces claires, texte bien lisible ; les bandes en haut des pages restent sombres.
- [ ] Windows 11 avec Mica, « Noir profond » : le fond reste noir (pas de fond d'écran flouté derrière).
- [ ] Apparence → « Fenêtre des Réglages » → « Fond des Réglages » : choisir « Dégradés » → les taches de couleur d'avant reviennent derrière une carte en verre ; « Noir profond » → retour au noir. Fermer et rouvrir les Réglages : le choix est gardé.
- [ ] En bas de la barre, la pastille d'état : « Ondine 1.2.4 · mises à jour automatiques » (ou « manuelles » si coupées). Mises à jour → « Rechercher maintenant » : la pastille dit « à jour » ou « version x disponible ».
- [ ] Avec le module Dictée activé (branche dictée) : la pastille dit « Prête · maintenir <la touche> » (ex. Ctrl droit).

## La bande en tête de chaque page

- [ ] Chaque page (Général, Mascotte, Parler à Ondine, Apparence, Comportement, Animations et halos, Onglets, Règles, Profils, chaque module, Confidentialité, Téléphones, Identifiants, Sauvegarde, Mises à jour, Performances, À propos) commence par une bande : grand titre, une phrase courte, la couleur de la page qui respire dans le coin en haut à droite.
- [ ] Des bulles montent ; passer la souris dessus les écarte, elles reviennent ensuite sur leur route.
- [ ] Une vague ondule en bas de la bande ; deux ou trois gouttes de la famille gomme flottent dessus, nagent, regardent autour d'elles et suivent la souris des yeux.
- [ ] Cliquer sur une goutte : elle saute, change d'expression (surprise, rire, coucou…) et fait un rond dans l'eau en retombant.
- [ ] Les gouttes changent d'une page à l'autre (Animations : étoile, soleil, flamme ; Profils : lune, soleil…).
- [ ] Mascotte : bouton « Faire venir Ondine » dans la bande ; À propos : « Voir les nouveautés ».
- [ ] Fenêtre étroite (la rétrécir au minimum) : une seule goutte, jamais sous le texte.
- [ ] Gestionnaire des tâches : Réglages réduits ou cachés derrière d'autres fenêtres → processeur à 0 % pour la fenêtre des Réglages. Faire défiler une longue page jusqu'à ne plus voir la bande → l'animation s'arrête.
- [ ] Paramètres Windows → Accessibilité → Effets visuels → « Effets d'animation » coupés : la bande est une image fixe (pas de bulles qui montent, pas de vague) ; un clic sur une goutte change seulement son expression.
- [ ] Performances → mode Éco (ou sur batterie avec l'économie automatique) : la bande devient une image fixe ; retour en Équilibré : elle revit sans rouvrir la fenêtre.

## Les sous-menus en pilules

- [ ] Une page à sous-menus (Mascotte, Comportement, Animations et halos, Onglets, Profils, Agents IA, Parler à Ondine, Équipe) montre ses sous-menus en pilules sous la bande, la pilule choisie de la couleur de la page.
- [ ] Cliquer une pilule : la barre latérale suit (le même sous-menu y est en gras) ; cliquer un sous-menu dans la barre : la pilule suit. La bande ne recommence pas (les gouttes continuent).
- [ ] Fermer et rouvrir les Réglages : le sous-menu choisi est gardé.
- [ ] Mode Simple : les sous-menus sans réglage essentiel sont cachés dans la barre ET dans les pilules ; ils reviennent en Complet.

## Le groupe Voix

- [ ] La barre commence par « VOIX » : Dictée, Notes d'appel, Statistiques, Dictionnaire, Styles (dans cet ordre), puis Ondine, L'île…
- [ ] Chaque page Voix s'ouvre avec sa couleur (Dictée turquoise, Notes d'appel corail, Statistiques vert, Dictionnaire jaune, Styles rose) ; la pastille de la page active dans la barre prend cette couleur.
- [ ] Module Dictée ou Notes d'appel désactivé : petit point gris à côté de la page dans la barre.
- [ ] Rechercher « dict », « notes d'appel », « styles » : les pages Voix sont dans les résultats et y mènent.
- [ ] Depuis l'île, un lien qui ouvre « voice:dictation » (ex. bouton de la dictée, branche dictée) : les Réglages s'ouvrent sur la page Dictée.
- [ ] Quitter une page Voix pendant qu'elle travaille (ex. un enregistrement de Notes d'appel) : elle s'arrête proprement. Changer un réglage depuis l'île pendant qu'on est sur une page Voix : la page n'est pas redessinée (rien ne s'interrompt).
