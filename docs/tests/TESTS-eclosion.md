# Tests Windows : l'éclosion de l'île

À faire avec `npm.cmd run tauri dev`. L'île doit être en haut de l'écran.

- [ ] Réglages → Apparence → Animations : la ligne « Éclosion au démarrage » est là, activée.
- [ ] Le bouton « Voir » : la goutte sort du haut de l'écran, s'étire en île, l'île éclate en paillettes.
- [ ] Ondine (votre mascotte, avec sa couleur et ses accessoires) sort de l'éclat, fait coucou et écrit « Bonjour Simon ! ».
- [ ] Elle ouvre grand la bouche, aspire les paillettes en spirale et gonfle, puis les souffle dans les trois anneaux (Onglets, Modules, Batterie ou Mascottes).
- [ ] Repli en goutte : l'île s'affine, se rétracte en mini-île, Ondine y glisse en tournant, boing, deux respirations.
- [ ] Deux lumières partent des coins du haut et se rejoignent en bas dans une étincelle.
- [ ] La vraie île revient en fondu sans saut.
- [ ] Un clic pendant l'animation passe directement au repli.
- [ ] Les clics à côté de l'île passent bien aux fenêtres dessous pendant l'animation.
- [ ] Sons : plop, éclat, aspiration, souffle, trois notes, boing, carillon. Muets si « Sons de clic » est coupé.
- [ ] Style Studio : un voile sombre autour de l'île pendant l'éclosion. Classique : pas de voile.
- [ ] Thème Verre : l'île dessinée reste lisible.
- [ ] Interrupteur coupé : plus d'éclosion au démarrage.
- [ ] Île sur le côté ou en bas, île-bouche, Ondine sur le bureau, mode Calme : pas d'éclosion, tout démarre comme avant.
- [ ] Premier lancement (profil neuf) : l'éclosion, puis l'assistant.
- [ ] Après une mise à jour : l'éclosion « Ondine X.Y.Z est là ! », puis « Quoi de neuf ».
- [ ] En anglais : « Hello! », « Getting your island ready… », « All set ».
